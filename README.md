# GraphRAG and Context Retrieval — Wikipedia Vote Network

**Course:** 42913 Social and Information Network Analysis | **Topic:** 2 — GraphRAG and Context Retrieval

This repository implements a simplified GraphRAG retrieval module using the Wikipedia Vote Network. The project frames context retrieval as a **link prediction** task: if an algorithm predicts a strong link from user `A` to user `B`, then `B` is treated as highly relevant context for `A`. By structuring knowledge as a graph, we can trace indirect relationships that keyword-based retrieval would miss entirely.

---

## Results at a Glance

`Precision@10` on the held-out test edges (2,807 source nodes evaluated):

| Method | Mean Precision@10 | Std Dev | Total Hits |
|---|---:|---:|---:|
| **Personalized PageRank** | **0.3369** | 0.2389 | 9,456 |
| Common Neighbors | 0.3029 | 0.2328 | 8,502 |
| Adamic / Adar | 0.3027 | 0.2320 | 8,496 |
| Jaccard | 0.2941 | 0.2320 | 8,254 |
| Random baseline | ~0.091 | — | — |

> **Best method:** `personalized_pagerank` — 3.7× better than random guessing.

## Project Goals

- Process the SNAP Wikipedia Vote Network dataset (103,689 directed edges, 7,115 nodes)
- Create an 80/20 random train/test split with negative sampling
- Implement four link prediction algorithms and compare their retrieval quality
- Rank candidate links per source node and evaluate with Precision@K
- Connect results back to the GraphRAG motivation: better link prediction = better indirect context retrieval

## Algorithms Implemented

| Algorithm | Type | Formula | P@10 |
|---|---|---|---:|
| Common Neighbors | Local | `\|N(u) ∩ N(v)\|` | 0.3029 |
| Jaccard Coefficient | Local | `\|N(u)∩N(v)\| / \|N(u)∪N(v)\|` | 0.2941 |
| Adamic / Adar | Local | `Σ 1/log(deg(w))` for shared neighbours | 0.3027 |
| Personalized PageRank | Global | Random walk with restart at source node | **0.3369** |

Local methods use an **undirected projection** of the training graph. Personalized PageRank uses the **directed training graph** (α = 0.85) to respect the direction of trust flows and discover multi-hop relationships.

## Quick Start

```bash
# 1. Create a virtual environment (short path avoids Windows long-path errors)
C:\Users\User\.pyenv\pyenv-win\versions\3.11.4\python.exe -m venv C:\venvs\graphrag
C:\venvs\graphrag\Scripts\activate
python -m pip install -r requirements.txt

# 2. Download the dataset from SNAP
python scripts/download_data.py

# 3. Clean the raw edge list
python scripts/preprocess_data.py

# 4. Create 80/20 split and sample negatives
python scripts/create_split.py --test-size 0.2 --negatives-per-positive 10 --seed 42

# 5. Run all four algorithms and evaluate
python scripts/run_experiments.py --top-k 10

# 6. (Optional) Re-run evaluation from saved scores
python scripts/evaluate.py --top-k 10
```

Then open the notebooks in VS Code using the `C:\venvs\graphrag\Scripts\python.exe` kernel.
