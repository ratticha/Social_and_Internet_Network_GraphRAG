# Data Splits

This folder stores the train/test evaluation setup for link prediction.

## Files

- `train_edges.csv`: edges kept in the training graph
- `test_edges.csv`: positive edges hidden for evaluation
- `negative_samples.csv`: sampled non-edges used as negative candidates

## How it was created

Generated by:

```bash
python scripts/create_split.py --test-size 0.2 --negatives-per-positive 10 --seed 42
```

## Current status

This step is complete.

## Current result

- `train_edges.csv`: `82,951` edges
- `test_edges.csv`: `20,738` edges
- `negative_samples.csv`: `207,380` edges

## Notes

- The split uses `--test-size 0.2`
- Negative sampling uses `--negatives-per-positive 10`
- These files were used successfully in the final experiment run
